Pixel icon on a 24×24 grid; use for every glyph in Monsey UI (never emoji, never another icon set).

```jsx
<Icon name="mic" />
<Icon name="dashboard" filled />   {/* active tab */}
<Icon name="warning-box" title="Cảnh báo" />
```

- `filled` renders an inverted tile — the system's "filled" state.
- Sizes 24 (default) or 48 only; never fractional scales.
